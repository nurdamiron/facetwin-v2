# FaceTwin: realistic preview test (free, by hand)

Goal: in about 20 minutes, see whether an AI photo editor makes previews as realistic as QOVES, on your own face, for $0. Then use the same previews for a small paid test with real women.

## 1. Set up (3 minutes)

1. Open **aistudio.google.com** in Chrome and sign in with a Google account.
2. Start a new chat and pick an **image model** in the model list (named "Gemini … Image" or "Nano Banana"). Text-only models can't edit photos.
3. Click **+** (or the attach icon) and upload one photo.
4. Copy one prompt from section 3, paste it, and send. Wait 5–15 seconds.
5. Download the result. To try another change, start a **new chat** with the original photo, so edits don't stack.

## 2. Photo tips (they decide the quality)

- Front-facing, eyes at the camera, phone at eye level, about an arm's length away.
- Daylight from a window in front of you. No harsh lamp or flash, no strong filters.
- Hair visible around the face. No hat, no sunglasses.
- For friends: only with their OK. Tell them it's a test and you'll delete the photos.

## 4. Score each result (write it down)

| Preview | Looks like a real photo? (1–5) | Still clearly me? (yes / no) | Would this help me decide? (yes / no) | Notes |
|---|---|---|---|---|
| Copper hair | | | | |
| Fuller brows | | | | |
| Round frames | | | | |
| Skin after 12 weeks | | | | |
| … | | | | |

- **Pass:** most previews score 4–5 and "still me" is yes. Then the realistic preview is good enough to sell.
- **If identity drifts** (the face changes a bit), add at the end of the prompt: *"The face must be pixel-identical to the original except for the requested change."*
- **If the change is too weak or too strong,** add *"subtle"* or *"clearly visible"* to the change.

## 5. The paid test with real women (the real question: will they pay?)

1. Find 10–15 women aged 28–45: friends of friends, Instagram, Telegram groups. Not close friends; they're too kind.
2. Message (adapt it):

   > Hi! I'm testing a new service: you send one selfie and get realistic photos of yourself with a new look (hair color, hairstyle, braids, brows, beard or mustache) plus a 12-week skin plan for your face. Want to try one look for free?

3. Make her 1 free preview with the prompts above and send it. Then offer: *"Want the full set (5 looks + your face report + 12-week plan)? It's $19."*
4. Count: how many say yes **and actually pay** (a card link or bank transfer; a "maybe" doesn't count).
   - **3 or more out of 15 pay:** build it into the app.
   - **0–1 pay:** ask each woman what would make it worth $19, and change the offer before writing more code.
